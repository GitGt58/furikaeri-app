🖥️ LM Studio のセットアップ（コマンドライン不要・完全無料）
① LM Studio をダウンロード・インストール
公式サイトからお使いのOSのインストーラーをダウンロードし、ダブルクリックしてインストール。
🔗 https://lmstudio.ai/
対応OS: macOS / Windows / Linux　※ターミナル操作不要
② モデルをダウンロード（GUIで操作）
  1. LM Studio を起動する
  2. 左メニューの「Search（🔍）」をクリック
  3. 検索欄に gemma3 や llama3.2 と入力
  4. 表示されたモデルの「Download」ボタンをクリック
💡 推奨モデル（日本語対応・軽量）
Gemma 3 4B — Google製・8GBメモリで動作
Llama 3.2 3B — Meta製・バランス型
③ ローカルサーバーを起動（GUIで操作）
  1. 左メニューの「Local Server（⇄）」をクリック
  2. 上部のプルダウンからダウンロードしたモデルを選択
  3. 「Start Server」ボタンをクリック
  4. 「CORS」スイッチを ON にする（重要）
⚠️ CORS を ON にしないとブラウザから接続できません
④ このアプリに設定を入力
エンドポイント URL：
http://localhost:1234/v1/chat/completions
モデル名：LM Studio の Server タブ上部に表示される文字列をコピー
例: lmstudio-community/Meta-Llama-3.2-3B-Instruct-GGUF
✅ 動作確認：下の「接続テスト」ボタンを押して「接続成功！」と表示されれば完了です。
